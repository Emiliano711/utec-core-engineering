### 0. Safe Print List

Implementación de la función `safe_print_list(my_list=[], x=0)`, que imprime hasta `x` elementos de una lista en una sola línea y devuelve la cantidad real de elementos impresos.

La función utiliza `try/except` para manejar el acceso a posiciones inexistentes, sin utilizar `len()` ni importar módulos externos.
